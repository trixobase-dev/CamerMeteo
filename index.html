Votre vie privée dans CamerMétéo

Trixobase Enterprise édite l'application "CamerMétéo". Nous respectons la confidentialité de vos données conformément à la législation en vigueur.

1. Données collectées

  • Localisation : Activée uniquement si vous l’autorisez. Elle sert à afficher la météo de votre ville : Douala, Yaoundé, Bafoussam, Garoua, etc. Vous pouvez refuser et sélectionner une ville manuellement.
  • Données techniques anonymes : Version Android, rapports de crash, pour améliorer la stabilité. Aucune information personnelle n’est collectée.

2. Utilisation et stockage

Votre localisation est utilisée uniquement pour interroger le service météo et n’est pas conservée sur nos serveurs. Les données météo sont mises en cache localement sur votre appareil pour le mode hors-ligne.

3. Partage avec des tiers

Nous n’utilisons pas vos données à des fins publicitaires ciblées. Les API météo tierces utilisées par l’application sont soumises à leurs propres politiques de confidentialité.

4. Vos droits

Vous pouvez retirer l’accès à la localisation à tout moment : Paramètres > Applications > CamerMétéo> Permissions.

5. Contact

Pour toute question relative à vos données : trixobase.ets@gmail.com
